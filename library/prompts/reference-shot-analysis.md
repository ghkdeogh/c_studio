# 참고 영상 분석·적용 요청 양식

진행 절차와 근거 기준은 [참고 영상에서 제작 설계로](../../craft/doctrine/reference-analysis.md)를 따른다. 아래는 특정 모델의 실행 문법이 아닌 분석·기획 양식이다. 빈 항목을 상상으로 채우지 않는다.

## 입력

- 참고 영상 URL 또는 로컬 파일 / 관심 구간:
- 우리 작품 BRIEF / 현재 제작 단계 / 유지할 대사와 기존 컷:
- 배우려는 것: 예를 들어 게스트 공개 순서, 조리 손동작, 반응 컷, 소리 연결.
- 실제 확보 자료: 자막 / 확인한 영상 구간 / 표본 화면 / 완료된 분석 결과.

## 분석 요청

실제 확인한 자료를 바탕으로 화면 전환을 나누고, 자동 결과가 여러 컷을 묶었다면 구분해 주세요. 설명마다 관찰·추정·확인 불가를 표시하세요. 원본에서 정보를 언제 주고 언제 감추는지, 화면 크기·피사체 행동·카메라·빛·소리가 관객의 이해에 어떤 역할을 하는지 설명하세요. 원본 장면의 복사 대신 우리 이야기에서 재사용할 원리를 골라 주세요.

## 컷 카드

| 항목 | 기록 |
|---|---|
| 근거 | 원본 ID·타임코드·확인 자료·컷 경계 확인 여부 |
| 이야기 역할 | 이 컷에서 새로 알게 되는 정보와 감정 변화 |
| 화면 | 샷 크기·구도·피사체 위치·시선 |
| 시작 → 종료 | 손·소품·재료·표정의 실제 상태 변화 |
| 피사체 움직임 | 방향·접촉·속도·반응 |
| 카메라 움직임 | 피사체와의 상대 이동·높이·거리·초점, 정지 선택 포함 |
| 빛과 화면 질감 | 확인한 특징 / 장비·렌즈 등의 추정 분리 |
| 편집 | 진입점·종료점·앞뒤 컷 관계·생략할 과정 |
| 소리 | 발화자·대사·행동음·음악·선행 또는 이어지는 소리 / 확인 범위 |
| 적용 | 우리 컷 ID·살릴 원리·바꿀 요소·필요 없는 원본 요소 |
| 제작 | 난도와 이유·기존 원본 활용 또는 새 생성·실패 시 단순화 대안 |
| 시간 | 목표 편집 길이 / 모델 확인 후 요청할 원본 길이 |

## 생성용 설계로 변환

**시작 이미지 설계:** 캐릭터 참조 역할, 위치와 시선, 손·도구·재료의 시작 상태, 구도와 빛. 다음 동작을 시작할 여지가 있는 프레임인지 확인한다.

**영상 동작 설계:** 시작 상태 → 핵심 행동 → 읽을 수 있는 반응·종료 상태. 피사체 움직임과 카메라 움직임을 별도로 쓴다. 정확한 대사와 발화자를 붙인다.

**편집 사용 설계:** 원본 중 사용할 사건, 앞뒤 연결, 버릴 대기·정리, 확보할 손/음식/반응 화면. 실제 생성 뒤에는 계획 초 대신 원본 프레임과 PTS로 검수한다.

**검수 질문:** 원리의 근거를 실제 확인했는가? 우리 서사에 필요한가? 첫 이미지와 행동이 맞는가? 과도한 동시 동작이 있는가? 한국어로 읽었을 때 의미가 맞는가? 생성 결과와 편집 사용 길이를 혼동하지 않았는가?
