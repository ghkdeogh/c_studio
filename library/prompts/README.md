# 프롬프트 관리

공통 장면 작성 구조는 [장면 프롬프트 작성 양식](scene-planning.md)을 따른다. 참고 자료의 장르·인물·모델별 제약을 모든 작품에 그대로 적용하지 않는다.

참고 영상으로 연출을 설계할 때는 [참고 영상 분석·적용 양식](reference-shot-analysis.md)을 사용한다. 근거 확인과 제작 단계별 절차는 [참고 영상에서 제작 설계로](../../craft/doctrine/reference-analysis.md)가 소유한다.

모델별 폴더에는 실제 사용한 프롬프트와 입력 역할을 버전별로 보관한다. 각 파일에 모델, 참고한 playbook·워크플로, 버전과 변경 의도를 기록한다. 미확정 항목은 미확정으로 표시한다. 비밀정보는 넣지 않는다. 확정 이야기는 작품 BRIEF.md, 실제 시도·비용·품질은 renders.md, 재사용할 피드백은 작품 feedback.json을 따른다.
