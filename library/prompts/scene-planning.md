# 장면 프롬프트 작성 양식

인물과 공간의 기준을 먼저 정한 뒤, 장면에서 변하는 행동과 감정을 쓴다. 생성 모델의 지원 기능·길이·입력 역할은 실행 전에 따로 확인한다.

## 1. 인물과 기준 자료
- 인물 ID / 이름 / 극중 역할 / 원하는 것 / 인물 관계.
- 얼굴·머리·체형 / 복장·소품 / 말투·표정·몸짓 / 장면마다 유지할 특징.
- 인물시트, 참고 사진, 표정·복장 상세를 구분한다. 정면·측면·후면·얼굴 확대 중 실제 확보한 자료만 표시한다.
- 작품의 인물 정보와 시트는 characters.json, 확정된 이야기와 관계는 BRIEF.md를 따른다.

## 2. 모든 컷이 공유할 기준
- 시대·공간 / 화면 스타일 / 빛과 색 / 인물·제품 기준 / 소리 방향.
- 계속 유지할 것과 사건 때문에 바뀌는 것을 나눈다. 젖은 옷, 상처, 손에 든 물건과 감정 변화도 기록한다.
- 원본 사진·시트·동작 영상마다 용도를 명시한다. 일반 참조와 강제 시작/종료 프레임을 혼동하지 않는다.

## 3. 장면별 작성 순서
- 장면 ID / 이야기 목표 / 관객이 알아야 할 정보 / 감정의 시작과 변화.
- 시작 상태: 누구와 무엇이 어디에 있고, 어느 손으로 무엇을 들었는지.
- 행동: 준비 → 동작 → 반응. 한 번에 판독할 수 있는 핵심 사건을 정한다.
- 종료 상태: 다음 컷으로 넘길 위치·시선·손·소품·감정.
- 카메라: 렌즈·거리 / 높이·각도·구도 / 이동 / 초점. 감정과 정보에 필요한 선택을 한다.
- 연기: 체중 이동·관절·시선·손 접촉·호흡을 실제 행동으로 쓴다.
- 대사: 화자 / 정확한 문장 / 말투 / 말하지 않는 인물의 반응.
- 소리: 현장음 / 행동 소리 / 대사 / 음악의 유무와 크기.
- 연결: 앞 컷 실제 종료 → 이번 컷 시작 → 다음 컷의 시작.

참고 영상이 있는 컷은 [분석·적용 카드](reference-shot-analysis.md)의 출처·확인 범위·살릴 원리를 먼저 연결한다. 참고 영상의 타임코드, 우리 컷의 목표 편집 길이, 생성 요청 길이는 서로 구분한다.

## 4. 제출 전과 결과 검수
- 목표 편집 길이와 모델 요청 길이를 분리한다. 대사와 행동이 실제 시간 안에 들어가는지 확인한다.
- 동일 시드는 모델이 지원할 때만 사용한다. 같은 시드만으로 얼굴이나 카메라가 고정된다고 보장하지 않는다.
- Blender에서 수치로 설계한 카메라도 렌더를 참고 입력으로 전달하면 모델이 재해석할 수 있다. XYZ 직접 제어와 영상 참고는 다르다.
- 긴 금지문·품질 수식어를 쌓기보다 실제 입력, 핵심 행동, 중요한 유지 조건을 우선한다.
- 같은 앵글 반복을 무조건 금지하지 않는다. 시선 연결·감정·원테이크 의도가 우선이다.
- 색·조명·시간 지시가 서로 충돌하지 않는지 확인한다. 실제 프레임·음향으로 통과 여부를 판정한다.

## 참고 자료
AI ASTRA, 「AI드라마 프롬프트 자료집」, 사용자가 제공한 로컬 파일 AI드라마_프롬프트자료집_AISTRA.docx의 PART 1–5를 참고해 작성했다. 인물·배경·소품 시트의 역할 분리, 공통 연속성 기준, 장면별 시작/종료·카메라·연기·대사·효과음 구조를 가져왔다. 원작의 인물·대사·서사·판타지 스타일은 새 작품에 복제하지 않는다. 시드 고정, 모든 앵글을 다르게 하기, 무조건 무음악 같은 조건은 해당 예시의 설정이며 우리 공통 규칙으로 채택하지 않는다.
