# 검수와 전달

작품 BRIEF.md의 확정 의도와 검수 기준을 확인하고 실제 결과물을 열어 비교한다. 확인할 수 없는 품질은 미검증으로 표시한다. 후보별 장점, 결함, 채택 또는 보류 이유를 작품 renders.md에 기록한다. 생성상태.md에는 채택판과 다음 행동만 갱신한다.
전달 파일의 존재·형식·열림을 확인한 범위만 보고한다. 공개·외부 전송은 사용자가 요청한 대상과 범위를 따른다.

## 영상 시간 검수 화면
사용자 요청에 따라 앞으로 영상 전달 시 소수점 세 자리 재생 시각, 프레임 이동, 느린 재생, 시작·끝점 표시를 기본 제공한다. 프레임 수와 시각은 실제 파일에서 읽고 모델 기본 fps로 추정하지 않는다. 원본과 편집본 각각에 적용한다. 브라우저 구간 표시는 사용자의 실제 편집 승인이나 project.json 변경으로 자동 간주하지 않는다.
기본 검수는 공통 제작실 http://127.0.0.1:8765 이다. project.json 등록만으로 새 작품·컷·이미지·영상이 자동 반영된다. _infra/creative-studio/web/review.js와 media_engine.py가 실제 PTS·프레임 구간 저장·비동기 이어붙이기를 담당한다. 등록과 출력 계약은 docs/studio/project-contract.md를 따른다. 별도 HTML이나 작품별 제어 코드를 새로 만들지 않는다.
