# 참고 영상에서 제작 설계로

참고 영상이 제공되거나 특정 연출을 배우려는 작업에 적용한다. 목표는 원본의 사건·대사·인물을 복제하는 것이 아니라, 관객에게 정보를 주고 감정을 바꾸는 방법을 우리 작품에 옮기는 것이다. 확정 이야기는 작품 BRIEF.md, 재사용 기록은 작품 feedback.json이 소유한다.

## 1. 확인 가능한 근거 확보

원본 URL·제목·선택 구간과 실제로 확인한 자료를 작품 `references/analysis/<reference-id>/`에 기록한다. 전체 자막, 직접 본 화면, 자동 분석 결과를 구별한다. 자막만 확보했으면 카메라 움직임이나 컷 경계를 봤다고 쓰지 않는다. 표본 화면 확인을 전 구간의 프레임 검수로 표현하지 않는다.

Higgsfield 분석 도구를 쓸 때는 현재 도구 정의를 확인하고 `video_analysis_create`의 작업 ID로 `video_analysis_status`를 조회한다. 완료된 결과만 분석 근거로 쓴다. 대기·실패를 완료로 표시하지 않는다. 긴 영상은 분석이 거칠어질 수 있다. 이용 요금·지원 입력은 현재 도구와 실행 조건으로 확인하며 참고 영상의 가격 설명을 정본으로 삼지 않는다. 일반적인 영상 분석에 생성·편집 스킬을 잘못 적용하지 않는다.

## 2. 장면과 실제 컷을 구별

자동 응답의 scene 또는 shot 명칭을 그대로 컷 번호로 확정하지 않는다. 한 분석 구간에 화면 전환이 여럿 있으면 하위 컷으로 나누고, 경계 미확인은 명시한다. 원본 시작·종료 타임코드와 길이, 화면상 근거, 관찰·추정·확인 불가를 기록한다. 렌즈·장비·프레임레이트는 화면 인상만으로 확정하지 않는다.

전체 흐름을 먼저 보고 도입, 중요한 행동, 전환 또는 결말 등 적용하려는 구간을 실제 화면과 대조한다. 자동 결과의 마지막 타임코드와 원본 길이도 비교한다. 완료 상태는 정확도 검증이 아니다. 누락이나 화면 불일치가 크면 해당 결과를 컷 설계의 근거에서 제외하고, 실제 확인한 구간만 사용한다. 소리 검수가 없으면 자막에 없는 효과음·음악 박자를 단정하지 않는다.

## 3. 우리 작품에 옮길 원리 선택

각 후보마다 `원본에서 한 역할 → 우리 장면의 필요 → 구체적 적용 → 버릴 원본 요소`를 적는다. 한 작품에서 우선 시험할 원리는 1~3개 정도로 좁힌다. 다른 장르의 화면비·말투·금지사항·카메라 움직임을 무조건 가져오지 않는다. 원본 영상 자체를 변형하는 방식과 새 장면을 설계하는 방식도 구분한다.

## 4. 컷 카드와 생성 입력 분리

[분석·적용 양식](../../library/prompts/reference-shot-analysis.md)으로 컷 카드를 만든 뒤 기존 [장면 작성 양식](../../library/prompts/scene-planning.md)에 연결한다. 시작 이미지에는 인물·공간·손·소품의 첫 상태를, 영상 프롬프트에는 그 상태에서 가능한 행동과 카메라의 경로를 쓴다. 두 사람 장면은 위치·시선·발화자·비발화자의 반응을 분리한다. 여러 행동이 충돌하면 한 생성에 몰아넣지 않고 별도 컷으로 설계한다.

프롬프트의 한국어 의미를 검토하고 실제 모델 문법은 craft/playbooks, 입력·길이 설정은 library/workflows의 해당 정본으로 변환한다. 모델 미정이면 실행용 프롬프트로 표시하지 않는다. 캐릭터시트와 실제 시작 이미지가 프롬프트의 상태와 맞는지 확인한다.

## 5. 생성 전에 편집의 목적 정하기

이야기의 한 사건, 생성 원본 한 개, 최종 편집 컷 한 개를 구별한다. 컷 카드에는 목표 편집 길이와 생성 요청 길이를 따로 쓴다. 준비·행동·정리를 전부 쓰는 대신 관객이 행동을 이해하는 진입점과 결과가 읽히는 종료점을 정한다. 빠른 삽입 컷과 반응을 읽을 여유를 대조한다. 모든 컷을 빠르게 자르거나 모두 움직이게 하지 않는다.

대사는 입이 보이는 구간을 보호하고 필요한 경우 음식·손 삽입 화면에 이어지는 소리를 설계한다. 소리의 선행·잔향 연결은 실제 음원과 편집 기능을 확인한 뒤 적용한다. 단순 연결 도구가 지원하지 않는 오디오 편집을 했다고 표시하지 않는다.

## 6. 제작 중인 작품과 회고

이미 만든 컷은 먼저 실제 사용 구간과 대체 가능한 기존 삽입 컷을 살핀다. 참고 영상을 배웠다는 이유만으로 확정 대사·컷·목표 길이를 바꾸거나 재생성을 시작하지 않는다. 사용자 요청에 맞는 편집안을 만들고 실제 PTS로 구간을 검수한다. 짧은 대안은 원본과 별도 버전으로 보존한다.

참고한 원리와 적용 대상은 작품 feedback.json에 출처·조건과 함께 기록한다. 문서 반영과 영상 품질 검증을 구별한다. 결과는 renders.md에서 판정하고 게시 후 성과는 같은 조건의 기록으로 비교한다. 한 편의 조회수만으로 특정 연출의 효과를 확정하지 않는다.
