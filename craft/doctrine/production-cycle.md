# 공통 제작 과정

1. 사용자 의도, 독자·관객, 형식, 제약, 검수 기준을 확인한다.
2. [피드백 반영 절차](feedback-cycle.md)에 따라 이전 작품의 재사용 기록과 적용 조건을 읽는다. 인물 기준은 작품 characters.json에서 확인한다. 이야기와 표현 방향을 제안하고 확정된 내용만 작품 BRIEF.md에 기록한다.
3. 참고 영상에서 제작 방법을 가져오는 작업은 [참고 영상 분석·적용 절차](reference-analysis.md)로 확인된 원리와 적용 컷을 정한다. 선택한 모델의 playbook과 워크플로 정본을 확인해 프롬프트를 준비한다.
4. 실행 요청과 허용된 자원을 확인한 뒤 해당 런북을 따른다.
5. 결과를 검수 기준으로 비교하고 작품 renders.md에 근거와 판정을 남긴다.
6. 채택판과 다음 행동은 작품 생성상태.md에 기록한다.

확정되지 않은 설정을 사실로 취급하지 않는다. 한 번의 비교에서 무엇을 바꿨는지 추적할 수 있게 기록한다. 사용자의 창작 방향을 임의로 확정하지 않는다.
